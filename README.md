## Run Locally

Clone the repository:

```bash
git clone https://github.com/congy1344/huynhcongy-portfolio.git
cd huynhcongy-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production Build

```bash
npm run build
npm start
```

The project does not require runtime environment variables. The resume is served from `public/resume.pdf`.

## Deploy on Vercel

Import [congy1344/huynhcongy-portfolio](https://github.com/congy1344/huynhcongy-portfolio) into Vercel with these defaults:

- Framework preset: Next.js
- Root directory: `.`
- Build command: `npm run build`
- Output directory: default

Every push to `main` triggers a new Vercel deployment.
